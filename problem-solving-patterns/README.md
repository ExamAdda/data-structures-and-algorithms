# DSA Problem-Solving Patterns

Patterns help you connect a new problem with a reusable approach.

| Pattern | Common signals | Typical applications |
|---|---|---|
| Two pointers | Sorted data, pairs, opposing ends | Pair sum, deduplication |
| Sliding window | Contiguous range, longest or shortest | Subarrays and substrings |
| Prefix sum | Repeated range calculations | Range sums, subarray counts |
| Fast and slow pointers | Cycles or middle element | Linked lists |
| Monotonic stack | Next greater or smaller element | Histograms, temperatures |
| Binary search on answer | Monotonic feasibility | Minimum capacity or maximum limit |
| Merge intervals | Overlapping ranges | Scheduling |
| Top-k | Repeated minimum or maximum | Heaps and frequency problems |
| Backtracking | Generate all valid choices | Permutations, N-Queens |
| Dynamic programming | Repeated states and optimal choices | Knapsack, paths, subsequences |

For each pattern, document its recognition signals, invariant, template, complexity, counterexamples and practice set.
