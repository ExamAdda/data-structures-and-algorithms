# Company-Wise DSA Preparation

Company tags should be used for navigation, not as a substitute for learning core patterns. Interview processes change, and past questions do not guarantee future questions.

## Recommended Format

For each company, record:

- Publicly reported problem or topic
- Difficulty and core pattern
- Source and date, when available
- ExamAdda solution link
- Related variations

Avoid copying proprietary interview material or claiming that a question is guaranteed to appear.
