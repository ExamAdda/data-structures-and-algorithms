# DSA Interview Questions

## Preparation Tracks

| Track | Focus |
|---|---|
| Beginner | Complexity, arrays, strings, basic searching and sorting |
| Intermediate | Linked lists, trees, heaps, graphs and common patterns |
| Advanced | Dynamic programming, advanced graphs and data structures |
| [Company-wise](company-wise/README.md) | Targeted revision after building core skills |

## Conceptual Questions

1. What is the difference between time and space complexity?
2. When should a hash map be preferred over an array?
3. Why does binary search require a monotonic search space?
4. How do BFS and DFS differ in memory usage and application?
5. What properties make a greedy algorithm correct?
6. How do memoization and tabulation differ?

## Coding-Interview Workflow

1. Restate the problem and clarify assumptions.
2. Work through a small example.
3. Describe a correct brute-force solution.
4. Identify constraints and optimize.
5. State complexity before coding.
6. Write readable code and test edge cases aloud.
7. Discuss trade-offs and follow-up variations.
