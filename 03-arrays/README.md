# Arrays

Arrays store elements in contiguous positions and provide constant-time indexed access.

## Learning Order

1. Traversal and basic operations
2. Minimum, maximum and second-largest element
3. Frequency counting and hashing
4. Two pointers
5. Sliding window
6. Prefix and suffix techniques
7. Kadane's algorithm
8. Interval problems
