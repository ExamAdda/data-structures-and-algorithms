# DSA Glossary

| Term | Meaning |
|---|---|
| Algorithm | A finite sequence of steps for solving a problem |
| Auxiliary space | Extra space used by an algorithm excluding the input |
| Data structure | A method of organizing and accessing data |
| Invariant | A condition that remains true during an algorithm |
| Stable sort | A sort that preserves the relative order of equal elements |
| Traversal | Visiting elements or nodes in a defined order |
